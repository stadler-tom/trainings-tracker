# Project rules

- Language: identifiers, comments, commit messages and technical messages in English; everything the user reads (UI, docs for users) in German.
- Keep it simple: small hobby project, no enterprise structures (no extra layers, interfaces, DI, repository pattern, state or router libraries) unless there is a concrete need.
- Requirements: "Lastenheft Trainings-App (Web-App)" (claude.ai doc) and the earlier "Lastenheft Trainings-Tracker".
- Production data: Tom's real Google Sheet must never be touched during development. Develop and test only against a copy or the template.
- Public repository: never commit keys, web API URLs, CSV links or personal data.
- Only implement what is requested; propose extras and wait for approval.
